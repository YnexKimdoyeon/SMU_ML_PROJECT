📦 SMU ML Project – 약제 분석 AI 플랫폼
약제 분석을 위한 AI 기반 프로젝트로,
총 3가지 모델 구성을 통해 약제 자동 분석 및 대응 방안을 제시합니다.

🧭 프로젝트 구성
알약 분류 모델

📷 이미지로 들어온 알약을 분류

약의 종류 또는 형태(예: 원형, 타원형, 색상) 맞추기

알약 부작용 유무 분류 모델

출력값: Yes 또는 No

주어진 알약이 보고된 부작용이 있는지 분류

중복 약제 기반 질병 예측 모델

복용 중인 여러 약제 정보를 입력받아

중복 처방/상호작용 정보를 활용해 관련 질병을 추정

🌐 전체 워크플로우
이미지 입력

촬영된 알약 이미지 입력

모델 1: 알약 분류

이미지를 통해 약 종류/형태 분류

모델 2: 부작용 분류 (Yes/No)

해당 약에 부작용 사례가 있는지 예측

모델 3: 질병 분류

복용 조합 정보 기반으로 질병 추정

최종 리포트 출력

분류 결과 + 부작용 여부 + 질병 예측 결과 제공
